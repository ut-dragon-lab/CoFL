# R2R-1200 evaluation reference

[R2R-1200](../benchmarks/r2r_1200/README.md) is the fixed selected subset used
for this navigation task. The dataset provides episode IDs and annotations;
model, runtime and output settings belong to the
[evaluation configurations](../configs/evaluation/README.md#r2r-online).

## Reference scores and scope

| Selected subset | Episodes | NE (m) | OS | SR |
| --- | ---: | ---: | ---: | ---: |
| R2R-1200 | 1,200 | 5.949960496450464 | 0.52 | 0.40 |

These descriptive reference values aggregate recorded per-episode outputs for
the selected IDs. They are not independent validation or official full-split
results. A fresh complete 1,200-episode rollout has not been performed for this
release, and the values are not a guarantee for a new evaluation. Report the
subset ID, checkpoint and execution protocol when comparing results.

## Model and evaluation conditions

The reference CoFL-S `best.ckpt` was 5,336,359,747 bytes, SHA-256
`015acb99eaf3fa8a47833e2c6cc6166eb6d18b274344789c7ed850a12763ca42`.
The sanitized release copy has SHA-256
`cce748914a88167a2566ffd724ed43f0f651841dcab25afcbef706f5ccd62b12`.
Its tensors and processor assets are unchanged; only private path metadata was
replaced. Historical results retain the original hash. Use a new result directory
for the release copy. Public checkpoint download is still pending.

After [preparing the data](../benchmarks/r2r_1200/README.md), set the model and
runtime asset locations following the
[evaluation guide](../configs/evaluation/README.md#r2r-online), then run:

```bash
uv run --locked python -m cofl.online --config configs/evaluation/cofl_s_r2r_online.yaml
```

Navigation requires the matching complete checkpoint, CoFL host dependencies,
Matterport3D `.glb`/`.navmesh` assets and a separate compatible Habitat
interpreter. The data preparation tool does not require or configure those
evaluation dependencies.

| Condition | Reference setting |
| --- | --- |
| Protocol / metric recipe | `cofl-s-vln-benchmark-v6` / `vlnce_official_core_v1` |
| Inference | `cofl-inference-v1`, 100×100 field grid, 100 integration steps, `policy_dt=0.01` |
| Language | FGR2R oracle progress, monotonic nearest-reference-edge selection, lookahead 6 |
| Observations | Single RGB-D frame; RGB 224×224, depth 256×256, HFOV 90°, sensor height 1.5 m |
| Simulator | Agent height 1.5 m, radius 0.1 m; depth maximum 10 m; sliding enabled |
| Clocks | Planner/controller/sensor/plant = 5/50/30/100 Hz |
| Limits | 500 predictions or 120 simulated seconds; at 5 Hz the prediction limit is approximately 100 seconds |
| NE / OS | Navmesh distance at the final plant XYZ pose / success at any recorded plant XYZ pose |
| Success | Explicit STOP and final navmesh distance strictly `<3 m`; `timeout`/`max_steps` are failures |
| nDTW / SDTW | Official GT locations, fastdtw; SDTW = nDTW × SR |

GT progress is privileged information and must be disclosed in comparisons.
The historical text-to-edge mapping is part of the evaluation implementation;
changing its behavior or other protocol settings requires a separate result.

The shipped evaluation config uses eager execution, 16 workers and batch size
16. The recorded reference includes more than one batching setup.
Batch shape and numerical execution can change later actions in a closed loop,
so matching the selected IDs does not guarantee identical recorded trajectories
or aggregate values. Record the execution settings with every new evaluation.

## Observed environment and validation

These versions were observed while packaging the evaluation workflow, not
recovered from a complete historical environment snapshot:

| Process | Observed versions |
| --- | --- |
| CoFL host | Python 3.12.12; PyTorch 2.5.1+cu124; Torchvision 0.20.1+cu124; NumPy 2.3.4; Transformers 4.57.1; fastdtw 0.3.4 |
| Habitat worker | Python 3.7.12; habitat-sim 0.1.7; NumPy 1.21.6; numpy-quaternion 2022.4.1; PyYAML 6.0.1 |

Use the host lockfile and a separate Habitat environment. Record resolved
versions, hardware, checkpoint identity and execution settings with new runs.

The earlier integrated workflow was checked against official FGR2R, all 1,200
episode/GT identities and their oracle providers. One real model/Habitat smoke
episode, original ID 1, produced NE=1.8215909004211426, OS=1 and SR=1, matching
its stored reference. That check preceded the separation of data preparation
from evaluation configuration and does not establish a new complete-cohort
result. Current software tests validate their stated code paths independently
of navigation quality.
